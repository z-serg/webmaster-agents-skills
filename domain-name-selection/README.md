# Skill domain-name-selection — подбор доменного имени

Навык для агента, который подбирает доменное имя для нового сайта или проекта
и доводит подбор до проверенных рекомендаций: генерирует не менее 50 подходящих
названий, проверяет занятость через WHOIS/RDAP, исследует историю свободных
доменов через Wayback Machine и точные запросы в Яндексе и Google, а затем
составляет обоснованный короткий список.

Навык различает три независимых свойства домена: качество имени, текущую
занятость и историю использования. Домен не объявляется «не дропом» только
потому, что архив или поисковик не нашли записей.

## Возможности

- **Генерация и отсев названий.** Минимум 50 уникальных основ имени по разным
  направлениям: действие или польза, тематическая ассоциация, метафора,
  короткое брендовое имя. Проверка благозвучности, запоминаемости и возможности
  продиктовать адрес без объяснения написания.
- **Особые правила для русскоязычных сайтов.** Латиница должна читаться как
  русское слово; в предполагаемом чтении исключаются ж, щ, ч, ш, й, х, ц и их
  транслитерационные замены (`zh`, `shch`, `ch`, `sh`, `kh`, `ts` и т. п.).
  Кириллические домены и `xn--` по умолчанию не предлагаются.
- **Проверка занятости.** Скрипт на стандартной библиотеке Python 3: WHOIS
  реестра (для `.ru`/`.su` — `whois.tcinet.ru`), резервный WHOIS.vu и RDAP по
  bootstrap IANA. Консервативные статусы: `taken`, `available`, `no_record`,
  `unknown`, `error` — ошибки, таймауты, CAPTCHA и HTTP 403/429/5xx не
  считаются свободой.
- **Исследование истории.** Wayback CDX с wildcard-формой `url=*.DOMAIN/` и
  обязательная дублирующая проверка через браузерный календарь архива при
  сбоях API. Открытие архивных снимков из разных периодов. Точный запрос
  `"domain-name.com"` в кавычках в Яндексе и Google через браузер.
- **Выводы со ссылками на факты.** Четыре вердикта об истории: подтверждена,
  есть следы, следов не найдено в проверенных источниках, проверка неполная.
  «Подтверждённый дроп» — только при свидетельстве прекращения прежней
  регистрации.
- **Ранжирование и отчёт.** Рекомендации 1–3 + таблица 5–10 лучших вариантов
  и воронка подборки. Полный список, CSV/JSON и сырые ответы сохраняются в
  рабочей папке проекта.

## Установка

Репозиторий: <https://github.com/z-serg/webmaster-agents-skills>

Скилл устанавливается в каталог навыков агента `~/.agents/skills/` — достаточно
скопировать туда папку `domain-name-selection` из репозитория.

### Быстрая установка (рекомендуется)

```bash
git clone https://github.com/z-serg/webmaster-agents-skills.git
bash webmaster-agents-skills/domain-name-selection/install.sh
```

Скрипт создаёт симлинк в `~/.agents/skills/`, поэтому скилл обновляется через
`git pull` без переустановки. Параметры: `--copy` — копирование вместо симлинка,
`--dest ПУТЬ` — другой каталог установки, `--force` — заменить существующую
установку (прежняя сохранится рядом с суффиксом `.bak.<дата-время>`),
`--help` — справка. Если цель уже установлена этим скриптом, повторный запуск
ничего не меняет.

### Ручная установка

Вариант 1 — клонирование и симлинк:

```bash
git clone https://github.com/z-serg/webmaster-agents-skills.git
mkdir -p ~/.agents/skills
ln -s "$(pwd)/webmaster-agents-skills/domain-name-selection" \
  ~/.agents/skills/domain-name-selection
```

Вариант 2 — копирование:

```bash
git clone https://github.com/z-serg/webmaster-agents-skills.git
mkdir -p ~/.agents/skills
cp -r webmaster-agents-skills/domain-name-selection ~/.agents/skills/
```

Для обновления повторите копирование.

Зависимостей нет: скрипту проверок нужен только Python 3 со стандартной
библиотекой. После установки перезапустите агент, чтобы он подхватил новый
навык.

## Использование

Навык срабатывает автоматически по запросам о подборе домена, поиске свободного
домена или проверке домена на дроп. Примеры запросов:

- «Подбери домен для нового сайта о...»
- «Проверь, свободен ли домен example.ru, и нет ли у него истории»
- «Придумай варианты названия и проверь, какие свободны в .ru»

Для проверки готового списка или одного домена полная генерация 50 имён
не запускается.

### Запуск скрипта вручную

```bash
python3 scripts/domain_check.py whois \
  --input work/domains.txt --out work/domain-research

python3 scripts/domain_check.py archive \
  --input work/domain-research/available.txt --out work/domain-research
```

Вход — текст UTF-8, по одному полному домену на строку (комментарии после `#`
допустимы). Ключевые параметры: `--timeout`, `--delay`, `--refresh`,
`--backend auto|registry|whois-vu|rdap`. Скрипт сохраняет индивидуальные JSON
в `whois/` и `archive/`, сырые ответы в `raw/`, сводные `<этап>.json` и
`<этап>.csv`, а также очередь браузерных поисковых проверок
`search_queue.csv`. Прерванную партию можно продолжить повторным запуском.
Подробности — в [references/checks.md](references/checks.md).

Требуется только Python 3 (стандартная библиотека, без внешних зависимостей);
поисковые проверки выполняются в браузере, а не скриптом.

## Границы

- Регистрация, покупка, платные проверки и обращение к владельцам доменов не
  входят в подбор без отдельного запроса.
- Навык не заменяет SEO-аудит и не даёт юридического заключения о товарных
  знаках: совпадения с действующими проектами проверяются как скрининг.
- «Следов не найдено» — не доказательство отсутствия прошлых регистраций,
  санкций или скрытой истории.
- Навык не обещает чистую ссылочную историю, отсутствие фильтров поисковиков
  или рост позиций.
