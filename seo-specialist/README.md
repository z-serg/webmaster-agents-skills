# Skill seo-specialist — пошаговое продвижение сайта

Навык для агента, который работает как SEO-специалист и ведёт сайт по
пошаговому алгоритму продвижения из 10 этапов. Методика — «Общая схема
продвижения сайта 2026» Антона Маркина:
<https://t.me/markin_seo/652>. Навык охватывает путь от базового
анализа сайта и изучения конкурентов — через аудиты, внедрение
доработок, семантику и создание страниц — к настройке релевантности,
ссылкам и бустерам роста, GEO-продвижению в нейросетях и
масштабированию.

Навык построен на принципе прогрессивной детализации: `SKILL.md`
держит карту этапов и сквозные принципы, а детальная методология
каждого этапа лежит в отдельном файле `references/` и читается по
мере необходимости.

## Возможности

- **Точечный вход и полный цикл.** Запрос вида «проверь индексацию»
  включает один этап; «продвинуть сайт» — всю схему по порядку 1 → 10
  с фиксацией результата каждого этапа.
- **10 этапов методологии:** базовый анализ сайта; анализ конкурентов и
  гибридная таблица элементов; аудиты; внедрение доработок; семантика;
  создание страниц под семантику; позиционка (настройка релевантности);
  ссылки и бустеры роста; GEO-продвижение в нейросетях; дальнейшее
  развитие и сети сайтов.
- **Технический аудит локальным скриптом.** `scripts/site_audit.py`
  (только стандартная библиотека Python 3) заменяет облачные краулеры:
  robots.txt, sitemap.xml, зеркала, SSL, битые ссылки, редиректы, дубли
  и пустые мета-теги, noindex/canonical, микроразметка JSON-LD,
  счётчики аналитики, viewport, изображения без alt, качество URL.
  Порядок аудита и разделение «скрипт / панель / человек» — в
  `references/checklist.md` (переработка SEO-чек-листа автора методики).
- **Сквозные принципы схемы:** конкуренты из Москвы; три ключевые
  правки (индексация, релевантность содержимому, коммерческие факторы и
  E-E-A-T); «не калечить страницы оптимизацией»; «слова не висят в
  воздухе»; регулярность закупки ссылок; ИИ на каждом этапе — от совета
  опытного сеошника до вайбкодинга страниц.
- **Только общедоступные сервисы.** Закрытые инструменты (например,
  ГАР, доступный лишь участникам закрытого сообщества) в навык не
  включены: для текстовой релевантности используется связка анализа
  текста Miratext + Just Magic, которую сама схема называет заменой, а
  также бесплатный SEO-анализ текста Advego.
- **Честные границы.** Навык не обещает позиции и сроки, не выдумывает
  метрики без данных, а серые техники схемы (PBN, накрутки ПФ,
  прогоны) описывает с рисками и без самостоятельного запуска.

## Установка

Репозиторий: <https://github.com/z-serg/webmaster-agents-skills>

Скилл устанавливается в каталог навыков агента `~/.agents/skills/` — достаточно
скопировать туда папку `seo-specialist` из репозитория.

### Быстрая установка (рекомендуется)

```bash
git clone https://github.com/z-serg/webmaster-agents-skills.git
bash webmaster-agents-skills/seo-specialist/install.sh
```

Скрипт создаёт симлинк в `~/.agents/skills/`, поэтому скилл обновляется через
`git pull` без переустановки. Параметры: `--copy` — копирование вместо симлинка,
`--dest ПУТЬ` — другой каталог установки, `--force` — заменить существующую
установку (прежняя сохранится рядом с суффиксом `.bak.<дата-время>`),
`--help` — справка. Если цель уже установлена этим скриптом, повторный запуск
ничего не меняет.

### Ручная установка

Вариант 1 — клонирование и симлинк:

```bash
git clone https://github.com/z-serg/webmaster-agents-skills.git
mkdir -p ~/.agents/skills
ln -s "$(pwd)/webmaster-agents-skills/seo-specialist" \
  ~/.agents/skills/seo-specialist
```

Вариант 2 — копирование:

```bash
git clone https://github.com/z-serg/webmaster-agents-skills.git
cp -r webmaster-agents-skills/seo-specialist ~/.agents/skills/
```

Для обновления повторите копирование. Зависимостей нет. После установки
перезапустите агент, чтобы он подхватил новый навык.

## Использование

Навык срабатывает автоматически по вопросам SEO-продвижения. Примеры
запросов:

- «Продвинь мой сайт example.ru в тематике …, регион — Казань»
- «Сайт не растёт, разбери по этапам, что не так»
- «Сделай технический аудит сайта example.ru локальным скриптом»
- «Сделай аудит: индексация, мета-теги, E-E-A-T»
- «Найди конкурентов и собери гибридную таблицу элементов»
- «Собери семантику и распредели по страницам»
- «Настрой текстовую релевантность страницы /uslugi/remont»
- «Составь план закупки ссылок на квартал»
- «Как попасть с брендом в ответы нейросетей?»

Для работы с платными сервисами (Keys.so, SpyWords, биржи ссылок) навык
попросит выгрузку или доступ — самостоятельно он не регистрируется и не
покупает.

## Границы

- Не обещает позиции, сроки и рост; результат этапов — проверяемые
  артефакты (таблицы, ТЗ, чек-листы, отчёты) в рабочей папке проекта.
- Закрытые сервисы не используются; их роль закрывают общедоступные
  аналоги (Miratext + Just Magic, Advego).
- Серые техники схемы описываются с рисками и юридическими нюансами и
  не запускаются без явного решения пользователя.
- Настройка рекламных кампаний и юридические заключения — отдельные
  задачи по прямому запросу.
