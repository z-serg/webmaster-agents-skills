# webmaster-agents-skills

Коллекция скиллов (навыков) для ИИ-агентов, помогающих веб-разработчикам
и SEO-специалистам. Каждый skill — самостоятельная папка с инструкцией
для агента `SKILL.md` и вспомогательными материалами: скриптами проверок,
справочниками и установщиком.

Скиллы устанавливаются в каталог навыков агента `~/.agents/skills/` и
срабатывают автоматически, когда запрос пользователя соответствует
назначению скилла. Коллекция будет пополняться.

## Скиллы

| Скилл | Назначение |
|---|---|
| [domain-name-selection](domain-name-selection/) | Подбор доменного имени для нового сайта: генерация не менее 50 вариантов, проверка занятости через WHOIS/RDAP, исследование истории свободных доменов через Wayback Machine и точные запросы в Яндексе и Google, обоснованный короткий список с вердиктами об истории. |
